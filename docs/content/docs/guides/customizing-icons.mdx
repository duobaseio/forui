Forui widgets use the icons defined in [`FIcons`](https://pub.dev/documentation/forui/latest/forui.theme/FIcons-class.html).
They default to [Lucide](https://lucide.dev/) icons in [`FLucideIcons`](https://pub.dev/documentation/forui_assets/latest/forui_assets/FLucideIcons-class.html),
which may not fit your application's custom design system.

To change the icons used across all Forui widgets, pass a custom `FIcons` to your [`FThemeData`](https://pub.dev/documentation/forui/latest/forui.theme/FThemeData-class.html).

<Callout type="info">
    Icons in `FIcons` should inherit their properties from the ambient [`IconTheme`](https://api.flutter.dev/flutter/widgets/IconTheme-class.html)
    created by Forui widgets. They should also implement `==` and `hashCode` so that recreating a `FThemeData` does not
    cause widgets to flicker.
</Callout>

## Custom Icon Widgets and SVG Icons

Some packages, especially those with duotone icons, use a custom icon widget to work around the default `Icon` widget's
limitations. Whether such a widget honors the ambient `IconTheme` depends on the package.

Implement `FIcon` to use them. Packages whose widgets inherit from the ambient `IconTheme` need nothing further:
* [`font_awesome_flutter`](https://pub.dev/packages/font_awesome_flutter)
* [`hugeicons`](https://pub.dev/packages/hugeicons)

Packages whose widgets do not inherit, and SVG icon sets, require additional work to retrieve and apply the inherited `IconThemeData`.
Wrap the widget in a [`Builder`](https://api.flutter.dev/flutter/widgets/Builder-class.html) so [`IconTheme.of`](https://api.flutter.dev/flutter/widgets/IconTheme/of.html)
