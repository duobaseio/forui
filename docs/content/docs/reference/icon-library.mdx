Forui Lucide and Phosphor are Flutter libraries that provide high-quality icons from [Lucide](https://lucide.dev/) and
[Phosphor Icons](https://phosphoricons.com/).

## Installation

<Callout type="info">
    Forui Lucide is bundled with the forui package. You don't need to install it separately if you installed `forui`.
</Callout>

From your Flutter project directory, run the following command to install Forui Lucide/Phosphor.

<Tabs items={['Lucide', 'Phosphor']}>
    <Tab value="Lucide">
        ```bash filename="bash" copy
        flutter pub add forui_lucide
        ```
    </Tab>
    <Tab value="Phosphor">
        ```bash filename="bash" copy
        flutter pub add forui_phosphor
        ```
    </Tab>
</Tabs>

## Usage

<Callout type="info">
    The best way to find a list of icons is to visit the [Lucide](https://lucide.dev/icons/)/
    [Phosphor Icons](https://phosphoricons.com/). website.
    We update the icons in the Forui Lucide package with each Forui release.
    If you notice a missing icon, please [open an issue](https://github.com/duobaseio/forui/issues/new).
</Callout>
