Forui Lucide is a Flutter library that provides a set of high-quality icons from [Lucide](https://lucide.dev/).

## Installation

<Callout type="info">
    Forui Lucide is bundled with the forui package. You don't need to install it separately if you installed `forui`.
</Callout>

From your Flutter project directory, run the following command to install Forui Lucide.

```bash filename="bash" copy
flutter pub add forui_lucide
```

## Usage

<Callout type="info">
    The best way to find a list of icons is to visit the [Lucide](https://lucide.dev/icons/) website.
    We update the icons in the Forui Lucide package with each Forui release.
    If you notice a missing icon in Forui Lucide, please [open an issue](https://github.com/duobaseio/forui/issues/new).
</Callout>
